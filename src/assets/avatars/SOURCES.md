# Avatar sources

The 11 avatars a player can choose (spec PRF-02, decision D21). Each file is the OpenMoji colour SVG,
unchanged, renamed after the avatar id of `src/domain/players.ts`.

| File | Emoji | Code point |
|---|---|---|
| `fox.svg` | fox | U+1F98A |
| `panda.svg` | panda | U+1F43C |
| `frog.svg` | frog | U+1F438 |
| `lion.svg` | lion | U+1F981 |
| `penguin.svg` | penguin | U+1F427 |
| `octopus.svg` | octopus | U+1F419 |
| `unicorn.svg` | unicorn | U+1F984 |
| `trex.svg` | T-Rex | U+1F996 |
| `cat.svg` | cat face | U+1F431 |
| `dog.svg` | dog face | U+1F436 |
| `owl.svg` | owl | U+1F989 |
