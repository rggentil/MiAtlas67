# Flag sources

The SVG flags in this folder are copied by `npm run data:flags` (`scripts/sync-flags.ts`). Do not edit them
by hand. The script skips the overrides listed below, so they survive a re-sync.

| Files | Source | Licence |
|---|---|---|
| Countries and extended entities (ISO 3166-1 and ISO 3166-2 codes) | [flag-icons](https://github.com/lipis/flag-icons) 7.6.0, `flags/4x3` | MIT, © 2013 Panayiotis Lipiridis |

## Overrides

set (spec DATA-05). Each file is the Commons artwork unchanged, placed on a 4:3 canvas (white margin above and
below) to match the other flags.
